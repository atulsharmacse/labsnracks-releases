# LabsNracks release downloads

This repository hosts LabsNracks desktop installers, checksums, release notes, and platform qualification records. It contains release documentation only; the application and website source repositories remain private.

## Download status

No desktop release has been published here yet. Download installers only from an attached asset on this repository’s Releases page once a release is published. Check the published SHA-256 checksum before installation.

## Beta qualification

Beta releases are previews and may be unsigned or have incomplete native platform testing. Each release will disclose signing, notarization, and native Windows or macOS test status. Packaging an installer does not establish that it has passed native device, networking, or persistence tests. Stable releases require verified signatures and completed native qualification.

## Bring your own licenses and images

LabsNracks does not include or distribute Cisco IOS, IOL/IOU, proprietary appliance images, or vendor license files. Users must obtain compatible images and licenses from their respective vendors and comply with the applicable terms.

Third-party engine notices and corresponding source information will accompany the relevant release assets.
